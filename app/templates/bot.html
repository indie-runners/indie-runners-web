Our crawler

Who it is

{% if crawler_name %}{{ crawler_name }} is the crawler{% else %}The crawler that sent you here is the one{% endif %} behind indierunners.co, a calendar of running races. Its user agent links to this page.

What it collects

Race facts: dates, distances, fees and registration. It reads them from organisers' own sites.

What it obeys

When it crawls a site, it reads that site's robots.txt and checks it before every page. It follows the group for its own name if there is one, otherwise the * group. A group that names only AI crawlers (GPTBot, ClaudeBot, CCBot) is not read as covering it.

Crawl-delay is honoured up to 60 seconds. A site asking for more is not crawled at all.

How to opt out

{% if crawler_name %}

Add this group to your robots.txt:

User-agent: {{ crawler_name }}
Disallow: /
{% else %}

Add a group to your robots.txt with Disallow: /, under User-agent: followed by the crawler's name: the part of its user agent before /1.0.

{% endif %}

Or email crawler@indierunners.co.
